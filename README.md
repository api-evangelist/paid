Paid (paid.ai) is the monetization platform for AI agents. It gives teams that build and sell AI agents the pricing, billing, and margin infrastructure to charge with flexible models — credits, usage-based, seat-based, and outcome-based pricing — while tracking the AI costs and delivered value behind every customer. Paid exposes a REST API (v1 and v2 on api.agentpaid.io), first-party SDKs for Node, Python, Go, and Java, a CLI, embeddable UI components, billing webhooks, an agent skill, and a hosted MCP server. Backed by EQT Ventures, Lightspeed Venture Partners, Seedcamp, and Techstars.

**Areas:** Company · Artificial Intelligence · Billing · Monetization · Payments · Usage-Based Pricing · AI Agents · FinOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
